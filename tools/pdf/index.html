PDF 편집·분할

PDF를 올려 페이지를 나누거나, 여러 PDF를 하나로 합치고, 순서·회전·삭제를 정리합니다. 파일은 서버에 올라가지 않고 이 컴퓨터 브라우저 안에서만 처리됩니다.

📄
PDF 파일을 여기에 끌어다 놓으세요 여러 개를 한꺼번에 올리면 올린 순서대로 이어 붙습니다

합치기

지금 보이는 순서대로 모든 페이지를 PDF 하나로 저장합니다.

골라서 저장

선택한 페이지(0장)만 새 PDF로 저장합니다.

나누기

한 페이지씩, 또는 범위를 적어 여러 PDF로 나눕니다. 여러 개는 ZIP으로 받습니다.

저장 이름

나눌 때는 이름 뒤에 _1, _2 … 또는 _p3 이 붙습니다.

페이지를 누르면 선택, Shift를 누른 채 누르면 범위 선택. 끌어서 순서를 바꿀 수 있습니다. 카드 위 버튼으로 한 장씩 회전·빼기도 됩니다.
