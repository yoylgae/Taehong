# 현장관리시스템

- `index.html`, `shell.js`, `shell.css` : 메인 화면(사이드바·홈)
- `ewp/` : 건설장비 작업계획서 (목록·등록·출력·엑셀 불러오기·일일점검표)
- `ewp/chk/` : 일일점검표 점검 부위 그림, `ewp/checklist-data.js` : 장비별 점검 내용
- `config.js` : Supabase 연결 정보

`main` 브랜치에 푸시하면 Vercel(equip-work-plan)에 배포됩니다.

## 접속 비밀번호
- `middleware.js` 가 모든 요청 앞에서 비밀번호를 확인합니다.
- 비밀번호는 코드에 없고 Vercel 프로젝트 환경변수 `SITE_PASSWORD` 에만 있습니다. 바꾸려면 Vercel 설정에서 값을 고치고 다시 배포하세요.
- 맞게 입력하면 30일 동안 기억합니다. 사이드바 '로그아웃'으로 해제됩니다.

## 직영실행 (jy/)
- 공사관리 › 직영실행. 달마다 한 묶음: 실행내역서 · 식대 · 인건비 · 노무비명세서 · 신분증·이수증·통장사본 · 자재구입 · 자재 사진대지 · 증빙서류
- 테이블: `jy_months`(달), `jy_rows`(sheet별 행, data jsonb), `jy_workers`(사람 인적사항, 달과 무관), `jy_files`(사진·서류), 저장소 `jy-files`(비공개)
- 주민번호 등 민감 자료라 **접속 비밀번호를 통과한 사람만** 읽고 쓸 수 있음:
  미들웨어가 `/__dbtoken` 으로 Vercel 환경변수 `DB_TOKEN` 을 내려 주고, 화면은 이를 `x-pms-token` 헤더로 보냄.
  DB 쪽은 `public.pms_ok()` 가 `private.gate.token` 과 비교(RLS·저장소 정책 모두).
  토큰을 바꾸려면 `DB_TOKEN` 과 `private.gate` 값을 같이 바꾸고 재배포.
- **엑셀 양식으로 저장** (`jy/export-xlsx.js`): 사용자가 고른 양식 .xlsx(지난달 파일)에서 값 칸만 바꿔 내려받기.
  서식·병합·인쇄설정·그림·수식은 그대로, 수식 안 단가 숫자만 교체(=SUM(AI5*160000)→…), 시트 간 행 연결(노무비명세서 8행=인건비 5행)에 맞춰 같은 순서로 채움.
  수식 결과를 다시 계산해 넣고 workbook에 fullCalcOnLoad 표시. 양식 파일은 서버에 올리지 않고 브라우저 IndexedDB에만 기억.
  '신분증,이수증,통장사본' 시트: '성명' 칸으로 사람 묶음(3줄)을 찾아 성명·주민번호·현장명·주소·전화번호를 채우고, 가장 높은 줄의 병합 칸 3개(신분증·이수증·통장사본)에
  사람마다 칸별 첫 사진(PDF는 1쪽)을 JPEG로 바꿔 비율 유지·가운데 맞춤으로 넣음. 예전 사진은 빼고, 모자란 묶음은 복사해 늘리고 남는 묶음은 지움.
- **근로계약서** 탭 (`jy/contract.js`): 계약서 양식 .xlsx(여러 회사 양식 시트 가능)를 저장소(templates/contract, jy_files.sheet='tpl-contract')에 올려 두고,
  소속마다 양식 시트를 골라 한 사람에 한 시트씩 복사·채운 엑셀을 만든다. 성명·주민번호·주소·전화·일당(H23)·계약기간·지급일·통장(견본에 계좌가 있을 때만),
  견본 근로자 이름이 들어간 서명란 글자도 새 사람으로 바꾼다. 인쇄 영역·주석·인쇄설정은 시트마다 복사.

## 홈 · 현장 지적도 (`map/`)
- 메뉴 공사관리 › 현장 지적도(탭)로 열림. 홈은 인사말·숫자 4개·최근 작업계획서·공사기간·바로가기만 둔 간단한 화면.
- 도면 원본: AutoCAD에서 뽑은 PDF → `pdftocairo -svg` + `pdftotext -bbox` → `map/tools/extract.py` → `map/base.json`
  (선 = 폴리선, 채움 = 삼각형 묶음, 지번 = 글리프 모양 + 글자 내용). 1pt = 10 도면단위.
  새 도면으로 바꿀 때: `pdftocairo -svg a.pdf a.svg; pdftotext -bbox a.pdf a.html; python3 map/tools/extract.py a.svg a.html map/base.json`
- 이름: 표시마다 `label`(말풍선 제목, 상세 창 🏷 이름 바꾸기 또는 입력 창 '표시 이름'), 아이콘 종류 이름은 두 번 눌러 바꾸고 site_map_doc.settings.kindNames 에 저장(현장 공통).
- **장비·작업 배치**: 아이콘(`map/icons.js`, 직접 그린 SVG)을 끌어다 놓으면 site_map_marks 에 저장. 말풍선은 겹치지 않게 자리를 골라 지시선으로 연결.
  날짜별(작업 시작~끝)로 보이고, 작업계획서(ewp_plans) 중 지도에 없는 장비는 오른쪽 목록에서 '위치 지정'.
- **도면 편집** (`map/cad.js`): 캔버스 캐드 — 선/폴리선/사각형/원/영역(면적)/글자/치수/거리, 이동·복사·회전·삭제, 그립 편집,
  창/걸치기 선택, 끝점·중간점 스냅(F3), 직교(F8), 실행취소, 명령줄(L, PL, REC …), 레이어(보이기·잠금·색), 축척 맞추기(CAL).
  수정분만 site_map_doc(id=1).edits 에 {add, mod, del, layers, settings} 로 저장 (원본 base.json 은 그대로).
- **출력** (`map/print.js`, 🖨 · Ctrl+P): 지금 화면/도면 전체, A4·A3, 가로·세로, 말풍선/아이콘만/도면만, 번호+작업 목록 표(2쪽). 도면을 250dpi로 다시 그려 인쇄 창(PDF 저장 가능)으로. 저장 안 한 수정도 그대로 나옴. 축척을 맞췄으면 축척 막대 표시.
- 두 테이블 모두 RLS `pms_ok()` (접속 비밀번호 쿠키 → /__dbtoken).

## 작업일보 (`ilbo/`, 공사관리 › 작업일보)
- 날짜마다 공사일보 · 출력일보 · 안전교육일지를 웹에서 고침 (ilbo_days.data, 자동 저장). '이어서 만들기' = 전날 누계→전일, 명일 작업→금일 작업, 잔재 누계 이어받기.
- 출력일보 직종 → 인원 투입 현황 금일(명) (settings.aliases: 유도→유도원, 살수→살수공, 덤프→덤프트럭).
- 엑셀 두 가지: **이 날 일보 엑셀**(exportDaily) = 그날 공사일보 한 장 + 출력일보 + 안전교육일지 시트(다른 파일에서 서식째 가져옴, `ilbo/xbook.js`)를 한 파일로, **작업일보 통합 엑셀**(exportReport) = 공사일보 (2)에 날짜를 이어 붙인 전체본.
- 엑셀(`ilbo/export.js`): 저장소 templates/ilbo/report.xlsx(작업일보) · edu.xlsx(안전교육일지)를 그대로 열어 값 칸만 바꿈.
  공사일보 (2): 양식 마지막 묶음(45줄)을 서식·병합·수식째 복사해 새 날짜를 이어 붙이고, 웹에서 고친 날짜는 같은 모양 묶음이면 덮어씀. 출력일보·안전교육일지는 그 날짜로 채움. 수식 칸은 건드리지 않음.
- 기존 일보 260일치(2025-11-04~2026-10-20)는 업로드한 '작업일보 1.xlsx'에서 가져옴 (src=import).

## 반입전 점검표 · 운전원 서약서 (`ewp/forms.js`)
- 작업계획서 작성 화면에서 장비명을 고르면 '반입전 서류' 칸에 출력 단추가 생김 (일일점검표 탭 목록에도 있음).
- 건설장비 안전관리 가이드(2026) PDF의 '점검표 ① 사용전' 쪽과 '운전원 서약서' 쪽을 그림(`ewp/forms/p쪽.jpg`)으로 깔고,
  머리칸(현장명·공정명·장비번호·제조사·형식·규격·연식·반입일·점검일자)과 운전원 이름 칸에 값을 얹어 A4 출력. 운전원이 여러 명이면 서약서를 한 명씩.
- 칸 위치는 `ewp/tools/gen-forms.py`가 PDF 글자 위치 + 그림의 표 선으로 계산해 `ewp/forms-data.js`에 저장. 살수차·집게차·아스팔트피니셔는 가이드에 서약서가 없어 덤프트럭·카고크레인·롤러 서약서로 대신.

## 작업허가서(PTW) (`ptw/`, 안전보건관리 › 작업허가서(PTW))
- 원청 시스템(HPMS) 작업허가서 조회 화면과 같은 짜임: 작업허가서 · 화학물질 사용계획서 · 화기작업 계획서 · 중량물 취급계획서 · 안전시설물 임시 해체/복구 작업계획서 (탭마다 ⭕/❌ = 작성 여부).
- 테이블 `ptw_docs`(ptw_no, start_date, end_date, status, data jsonb) · RLS pms_ok. 고치면 자동 저장.
- 작업허가서: 기본정보·결재자, 작업 공종(작업팀장·작업지휘자 대상·허가기간 7일 작업일 체크), 허가 작업(세부공종·작업활동·장비), 작업인원·보호구, 위험성평가(발생빈도×위험강도 → 등급 자동: 1 하(F) 2 중(E) 3 중(D) 4 상(C) 6 상(B) 9 상(A)), 검토 결재의견(사업수행팀·보건·안전).
- '+ 새 작업허가서' / '다음 주로 복사' = 최근 허가서를 다음 7일로 이어서 (결재의견·작업일 체크 비움). '이전 위험성평가에서 가져오기' = 다른 허가서의 위험성평가를 골라 넣기.
- 건설장비 작업계획서(ewp_plans) 연동: 허가기간에 작업하는 장비를 허가 작업 · 중량물 취급계획서에 가져오기 (굴착기=굴삭기 같은 장비로 봄).
- 인쇄(`ptw/print.js`): 갑지(작업허가서만) · 통합(작성한 계획서 모두), A4 가로.
- 첫 자료: 업로드한 조회 화면(GF32-2026-00232, 2026-10-23~29)에서 가져옴.

## 월간 위험성평가 (`ra/`, 안전보건관리 › 위험성평가) — 작업허가서와 연계
- 원청 '협력사 위험성평가 등록 / 월간 위험성평가 조회'와 같은 짜임. 테이블 `ra_months`(ym 유일, status, data jsonb) · RLS pms_ok.
  data = { ym, title, company, sign{sub,team,health,safety,lead:{name,date}}, tree[{wt1, items[{wt2, acts[]}]}], rows[{wt1,wt2,wt3,src,factor,type,freq,sev,measure,re,comment}], files{meeting,schedule} }
- ① 위험성공종 세팅: 현대건설 표준 위험성공종(STD_WT1, `ptw/ptw-data.js`)에서 작업공종을 고르고 세부공종·작업활동을 붙임. 칩 숫자 = 위험요인 수, 분홍 = 이번 달 허가서에 있는 작업활동.
- ② 위험요인-대책: 작업활동별로 위험요인 입력(빈도×강도 → 등급 자동), '이전 달에서' = 다른 달 같은 작업활동 위험요인 가져오기. '+ 새 달' = 전월 이어서 / 공종만.
- ③ 작업허가서 연계: 이 달에 걸친 허가서 목록, 허가 작업 작업활동이 공종 세팅·위험요인에 있는지(없으면 추가 단추), 허가서에만 있는 위험요인을 구분 'PTW'로 넣기('현장입력'은 미리 체크).
- 인쇄(`ra/print.js`): 조회 화면처럼 작업공종·세부공종·작업활동·구분 칸 합치기, A4 가로.
- 작업허가서 쪽 연계 (`ptw/app.js`): '📚 위험성평가 공종에서 고르기'(허가기간 달의 공종 세팅에서 작업활동 골라 허가 작업·작업 공종·위험요인 한 번에), '📚 위험성평가에서 가져오기'(월간 위험성평가 + 다른 허가서, '이 허가서 작업활동만' 거르기, 구분 PTW로 들어감), 허가 작업마다 위험요인 수(0이면 빨강·경고), '↗ 월간 위험성평가에 반영'(그 달 ③ 화면 열기).
- 탭 사이 이동은 셸 메시지 {pms:"open", id, hash:"#id=…" / "#ym=…"}, 두 화면 모두 hashchange 로 다시 불러옴.
- 첫 자료: 2026-10(결재완료, 조회 화면 저장본의 위험요인 100건 — 저장본에 100줄까지만 들어 있었음), 2026-11(작성중, 등록 화면의 공종 세팅).
